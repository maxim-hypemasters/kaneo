---
title: "Export tasks"
openapi: "GET /task/export/{projectId}"
---

JSON and CSV exports include each item's explicit `type`: `task`, `bug`, or
`feature`. Progress totals labeled Tasks include both Tasks and Bugs.

JSON version 3 includes portable item keys, Feature membership, milestone definitions, and milestone links. Import the complete document to retain its hierarchy.

Version 3 preserves release definitions, milestone lead/status/priority/release, Feature archive state, and immutable planning-history snapshots. Older hierarchy files remain accepted; former Feature planning values become history rather than active fields. Imported releases require `project:update`, and assigning a nonnull milestone lead requires `task:assign`.
